2 · O que vai no pacote?

O compilador cria o manifesto e transforma DashPT em DashCode, a linguagem que o runtime atual já interpreta.

Atenção: objetos de fase e interfaces serão salvos no pacote como dados de projeto. O runtime atual ainda não possui o adaptador Cocos que desenha objetos/UI dentro do Geometry Dash. Eles não serão apresentados como recursos ativos no jogo antes dessa integração.

3 · Código do mod

Comandos: fale, crie variavel, defina, some, se, senao, repita, fim e comandos de interface. Ver lista completa →

Use aspas para textos. Condições aceitam ==, !=, >, <, >= e <=. A indentação é livre.

4 · Rascunho de objetos Geometry Dash

Adicione objetos ao mapa de dados do projeto. As coordenadas são valores do editor, não pixels do celular.

5 · Montador de interface (UI Builder)

Monte a estrutura de uma interface para seu mod.

Sua interface aparecerá aqui.

6 · Resultado da compilação

Clique em Validar e compilar para ver o DashCode gerado.
Pronto para criar. A validação não executa código no jogo.

7 · Como importar no GD Hub

  1. Gere o arquivo .gdhb.
  2. Abra o GD Hub Mod Loader no Android.
  3. Entre no gerenciador de mods e escolha importar/instalar pacote.
  4. Selecione o arquivo salvo no aparelho.

O pacote usa GDHB v1, com manifest.json e src/main.dash obrigatórios. O loader executa os comandos DashCode reconhecidos pelo runtime atual.

8 · Biblioteca de peças de código

Peças independentes de código, não blocos Scratch. Toque para inserir no cursor do editor DashPT.

API: GDHubPieces.registerPiece(), insertPiece(), search() e getAll().

9 · API de construção de fases

Crie objetos, grupos, triggers e propriedades. Exportação para level/build.json.

Nenhum elemento.

Isto gera dados estruturados. O adaptador nativo Cocos2d-x ainda precisa interpretar os dados para alterar fases reais no Geometry Dash.
