Comandos DashPT

Referência dos comandos em português brasileiro usados para programar mods no GD Hub.

← Voltar ao Mod Creator

Importante: os comandos de lógica abaixo são convertidos para DashCode e executados pelo interpretador atual. Os comandos de interface são compilados pelo Mod Creator para ui/layout.json. A estrutura da UI fica dentro do pacote, mas ainda depende do adaptador nativo para aparecer dentro do Geometry Dash.

1. Variáveis e mensagens

fale "Olá!"Adiciona uma mensagem à saída do mod. Aceita valores e interpolação com {variavel}.
crie variavel nome = "Cube"Cria uma variável de texto, número ou verdadeiro/falso.
defina pontos como 10Altera uma variável que já existe.
some 5 em pontosSoma um número a uma variável numérica existente.
crie variavel jogador = "Cube"
crie variavel pontos = 0
some 25 em pontos
fale "{jogador} fez {pontos} pontos!"

2. Condições e repetições

se pontos >= 10Inicia um bloco condicional.
senaoInicia a alternativa de um bloco se.
repita 3Repete o bloco. Aceita de 0 a 1000.
fimFecha o bloco se ou repita.
crie variavel pontos = 0
repita 3
    some 10 em pontos
fim
se pontos >= 30
    fale "Desafio concluído!"
senao
    fale "Continue!"
fim

Comparadores: == igual, != diferente, > maior, < menor, >= maior ou igual, <= menor ou igual.

3. Criar painéis de interface COMPILADOR

crie painel "menu" em 20, 20 tamanho 240, 160Cria um painel chamado menu. Os valores são posição X/Y e largura/altura.
crie painel "menu" em 20, 20 tamanho 240, 160

O nome do painel deve ser único. Crie o painel antes de adicionar componentes.

4. Adicionar componentes de UI COMPILADOR

adicione texto "Bem-vindo!" no painel "menu"Adiciona um texto ao painel.
adicione botao "Jogar" no painel "menu"Adiciona um botão.
adicione imagem "logo.png" no painel "menu"Adiciona uma referência de imagem.
adicione alternador "Ativar mod" no painel "menu"Adiciona um alternador (toggle).
adicione barra "Progresso" no painel "menu"Adiciona uma barra de progresso.
crie painel "menu" em 20, 20 tamanho 240, 160
adicione texto "Meu primeiro mod" no painel "menu"
adicione botao "Jogar" no painel "menu"
adicione alternador "Efeitos ativados" no painel "menu"
adicione barra "Progresso" no painel "menu"

Esses comandos geram a árvore de componentes em ui/layout.json. Eles ainda não desenham a interface no jogo.

5. Regras da linguagem

  • Use português brasileiro nos comandos.
  • Textos devem ficar entre aspas duplas.
  • Use # no começo da linha para comentários.
  • Uma instrução por linha.
  • Use fim para fechar cada bloco de condição ou repetição.
  • Os comandos de UI devem estar fora dos blocos de lógica nesta versão do compilador.

6. Exemplo completo

# Dados do mod
crie variavel jogador = "Cube"
crie variavel nivel = 1
fale "Olá, {jogador}!"

# Interface do mod
crie painel "principal" em 20, 20 tamanho 260, 180
adicione texto "Painel do jogador" no painel "principal"
adicione botao "Continuar" no painel "principal"
adicione alternador "Mostrar efeitos" no painel "principal"

# Lógica
repita 3
    some 1 em nivel
fim
se nivel >= 4
    fale "Nível atualizado!"
senao
    fale "Nível inicial"
fim

7. Biblioteca de peças independentes e API de construção

O Mod Creator inclui 3.420 peças independentes para inserir no editor de código, sem blocos visuais Scratch. A API de construção permite criar/configurar objetos, grupos e triggers, associar objetos a grupos e remover elementos. Os detalhes estão em Documentação técnica da API.
