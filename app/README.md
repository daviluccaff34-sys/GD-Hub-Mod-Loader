# GD Hub Android companion app

This is the first Android interface for importing, listing, validating and running DashCode packages with the native runtime.

It is a **companion manager**, not yet an in-game overlay or a Geometry Dash process integration. The app only reads files selected by the user through Android's document picker and stores copies in its private app directory.

Supported build ABIs: armeabi-v7a and arm64-v8a.
