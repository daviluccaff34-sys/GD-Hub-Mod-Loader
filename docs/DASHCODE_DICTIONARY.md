# DashCode — dicionário inicial de elementos (1.200)

Este arquivo reúne **1.200 identificadores/propriedades propostos** para a linguagem simples do GD Hub.

Eles **não são comandos completos**. São nomes que poderão aparecer depois de palavras simples como `get`, `set`, `when`, `show` ou `hide`. Por exemplo:

```text
get player.position
set player.speed to 2
when player.death
    show ui.message
end
```

Os exemplos acima ilustram a ideia; a gramática e as APIs ainda serão definidas. Um identificador listado aqui não significa que a função já exista no loader.

## Como ler
- `player.position`: posição do jogador.
- `level.name`: nome da fase.
- `editor.selection`: seleção atual do editor.
- `trigger.group_id`: grupo associado a um trigger.
